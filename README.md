# QQ Agent × CHUNITHM 扩展

给 QQ Agent 用的两个 CHUNITHM（中二节奏）扩展：

- **技能 `chunithm`**：群里有人问官方更新、曲目定数、落雪成绩时，由模型按需调用三个工具查询并回答。
- **插件 `chunithm-push`**：定时检查官方 X 和官方网站，有新公告就自动推送到白名单群。

## 功能

### 技能：中二节奏情报站

| 工具 | 作用 |
| --- | --- |
| `chunithm__news` | 抓取官方 X（@chunithm）和 CHUNITHM 官方网站的最新公告，返回日文原文和链接 |
| `chunithm__song` | 按曲名、常见别名或曲目 ID 查询落雪 LXNS 曲目库：BPM、分类、版本、各难度定数、谱师、物量 |
| `chunithm__player` | 按 QQ 号或好友码查询落雪 LXNS 玩家资料、Rating、Best 30、Selection 10、New 20 |

特点：

- 曲目和成绩数据以**落雪 LXNS** 为准，不使用水鱼。
- WORLD'S END 谱面会合并回原曲，输出星级和属性，不会出现重复条目或「定数 0」。
- 官方 X 走第三方镜像 FxTwitter；失败时官网结果照常返回，不会整个查询失败。
- 查分需要落雪开发者密钥，未配置时返回申请指引，不会编造成绩。

### 插件：中二节奏情报推送

- 默认每 15 分钟检查一次官方网站和官方 X。
- 有新公告时推送到白名单群，默认一次最多 5 条。
- 首次运行只记录现有情报、不补发，避免装好后刷屏（可在设置中打开首次补发）。
- 默认安静时段 1:00–7:00，不检查、不推送。
- 推送走 QQ Agent 控制台的本地发送接口：经过群白名单校验，并写入聊天存档。
- 插件状态卡会显示检查间隔、目标群、数据源、上次检查/推送、已记录条数、最近错误。

## 安装

1. 找到 QQ Agent 的安装目录，例如 `D:\QQ Agent`。
2. 把 `skills/chunithm` 整个文件夹复制到 `<QQ Agent 安装目录>\resources\app\skills\chunithm`。
3. 把 `plugins/chunithm-push` 整个文件夹复制到 `<QQ Agent 安装目录>\resources\app\plugins\chunithm-push`。
4. QQ Agent 自带热重载，文件落盘后会自动加载，不需要重启。

加载成功后：

- 「技能」页会出现**中二节奏情报站**，工具列表里能看到上面三个工具。
- 「插件」页会出现**中二节奏情报推送**，并显示一张状态卡。

## 配置

### 落雪开发者密钥（查分用）

1. 到 <https://maimai.lxns.net/developer/apply> 申请落雪开发者权限。
2. 在 QQ Agent「技能 → 中二节奏情报站 → 落雪开发者密钥」里填入密钥并保存。
3. 让被查玩家在落雪「账号设置 → 隐私设置」里打开：
   - 允许读取玩家信息
   - 允许读取谱面成绩

没有密钥时，官方情报和曲目/定数查询仍然可以正常使用，只有查分不可用。

### 推送插件

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 启用自动推送 | 开 | 总开关 |
| 推送到哪些群 | 留空 | 留空 = 白名单里的全部群；也可以填群号，多个用逗号分隔 |
| 检查间隔 | 15 分钟 | 建议不低于 10 分钟 |
| 包含官方 X | 开 | X 走 FxTwitter 镜像，偶尔会失败 |
| 包含官方网站 | 开 | 官网接口更稳定，建议保留作为兜底 |
| 一次最多推几条 | 5 | 超出的会在消息末尾提示去官网看 |
| 首次运行也补发旧情报 | 关 | 打开后第一次检查就会推最新几条 |
| 安静时段 | 1:00–7:00 | 开始和结束设成相同值可关闭 |

## 数据源

- 官方网站新闻接口：`https://info-chunithm.sega.jp/`
- 官方 X：[@chunithm](https://x.com/chunithm)（通过 FxTwitter 镜像读取）
- 曲目、别名、成绩：落雪 LXNS `https://maimai.lxns.net/`

本项目与 SEGA、CHUNITHM 官方、落雪 LXNS 均无隶属关系。官方情报版权归 SEGA 所有；落雪数据版权归落雪及相应玩家所有。

## 已知限制

- 落雪查分必须配置开发者密钥，并且玩家要允许第三方读取；否则接口会返回 401/403。
- 官方 X 通过第三方镜像读取，网络不佳时可能失败；插件和技能都会用官方网站兜底。
- 插件推送不经过 QQ Agent 的 SendQueue 限频（每轮最多发一条），以避免自动推送被限频吞掉。
- 首次运行时不会补发历史公告，需要最新内容请手动打开「首次运行也补发旧情报」。

## 隐私

仓库中不包含任何 API 密钥、QQ 号、好友码或玩家成绩。密钥只保存在使用者本机的 QQ Agent 配置里。

## 兼容性

- QQ Agent 0.4.x
- Windows
- 技能 `apiVersion: 1`，插件 `apiVersion: 1`
- 需要 QQ Agent 的 `web_fetch` 权限
